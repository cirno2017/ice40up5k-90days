3. 按钮变化与主时钟没有固定相位关系；如果变化落在触发器的建立、保持时间窗口附近，可能引发亚稳态。两级同步给第一级更多恢复时间，从而降低亚稳态传播到后续逻辑的概率，不能保证风险为零.
两级同步也不等于消抖，更不保证捕获任意窄脉冲.
