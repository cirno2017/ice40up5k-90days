# iCESugar iCE40UP5K：90天 Verilog 与 FPGA 学习计划

周期：2026-09-18 至 2026-12-16。每天2–3小时，共180–270小时。日期与提醒均以北京时间（Asia/Shanghai，UTC+8）为准。第1天从9月18日开始；9月17日晚可自愿整理器材，不计入90天。

## 目标与安排原则

完成后应能独立编写中小型可综合Verilog模块、自检testbench、PCF及构建脚本；解释组合逻辑与时序逻辑、同步与亚稳态、FSM、握手和FIFO；完成综合、布局布线、时序检查、烧录和仪器验证。这里的“掌握”限定为入门项目需要的可综合RTL能力，不等于掌握Verilog全部语言特性、复杂CDC或大型FPGA工程。

你已有STM32/C/C++经验，并已接触点灯、计数和开源工具链。前两周重点是补齐原理和独立复现；已熟练的实验可把时间用于自检和边界测试，无需重新安装可用环境。90天以Verilog-2001/2005可综合子集为主，测试中如使用SystemVerilog辅助语法须明确标注。暂不把软核CPU、NPU、Linux或复杂总线纳入必做范围。

每天标准安排：20分钟复盘/概念，70分钟写代码，40分钟仿真或上板，20分钟记录，总计150分钟。只有2小时时压缩为15+55+35+15分钟；有3小时时额外30分钟做边界测试或2–4道对应练习。每7天的验收日依然保持2–3小时，但不增加新大模块。

遇到问题先保存最小失败案例，再区分语法/仿真、综合/约束、接线/仪器三类排查。一天内不必硬完成所有项；先用周验收和最后缓冲日补课。提醒默认按日历推进，不会假定你昨天已经完成；若连续落后超过2天，应根据你的反馈重新排程，而不是堆叠两天任务。

硬件依据：用户提供的《iCESugar iCE40UP5K 原理图.pdf》，单页，标注iCESugar v1.5、iCE40UP5K-SG48、2020/6/17。请以实物版本和跳帽状态做最后确认。官方iCESugar-nano使用LP1K，与本计划的UP5K板卡不同，不能混用PCF。

| --- | --- |

| 外部测试接口 | 优先从PMOD3选择闲置GPIO；顶层名→网络名→FPGA封装脚→排针位置逐项核对 |

以上引脚来自所附原理图；不要把原理图网络名中的数字直接当封装脚号。板载F103是iCELink的一部分，不要求修改其固件；外部测试信号可使用你已有的F401/F103开发板。

开发路线：Windows 11 + WSL2 Ubuntu，继续用OSS CAD Suite中的Yosys、nextpnr-ice40、IceStorm，以及Icarus Verilog和GTKWave。编辑器可继续使用CLion；语言支持不影响命令行工具链。已能工作的版本先固定并记录，学习期间不追每日更新。Windows端访问iCELink虚拟U盘和串口，可减少早期USB转发配置工作。

流程是RTL → Icarus仿真 → Yosys综合 → nextpnr布局布线/时序检查 → icepack生成bin → iCELink烧录 → 示波器/串口验证。器件用UP5K、封装SG48、主时钟约束12MHz；典型nextpnr选项为`--up5k --package sg48 --freq 12`，实际命令以已验证版本的帮助和项目Makefile为准。PCF引脚位置约束不能代替主时钟频率约束；主时钟报告通过也不等于异步输入或板外接口已被完整验证。

现有器材即可开始：开发板、USB数据线、杜邦线、面包板、STM32板、示波器及逻辑分析仪；可增加一个普通按钮和合适上拉电阻。前90天不强制购买屏幕、额外开发板或高速仪器。

## 最终项目：串口控制的脉冲测量与PWM实验台

FPGA用同一个12MHz主时钟并行运行测量、PWM及串口。STM32作独立信号源，电脑发命令并做显示/数值换算，示波器负责交叉核对。

| 功能 | 核心规格与验收 |
| --- | --- |
| 事件累计 | 一路外部上升沿累计，32位；串口清零；回绕/溢出行为明确定义 |
| 门控测频 | 连续1秒窗口计数并锁存；首先验证10Hz–100kHz的实验范围，不宣称这是芯片最高能力 |
| 周期与高电平时间 | 返回主时钟ticks，含有效、超时/溢出标志；低频优先看周期法 |
| PWM输出 | 固定周期、8位设置值；0恒低、255恒高，其余为值/256；默认12MHz/256=46.875kHz；配置在周期边界生效 |
| UART | 115200、8N1；R+换行读结果，C+换行清零累计计数，Pxx+换行设置PWM（xx为00–FF）；支持CRLF；一问一答 |
| 状态回复 | 一次性快照，返回累计、窗口计数、周期ticks、高电平ticks和状态；固定十六进制字段；格式在第69天冻结 |
| 异常处理 | 无信号、坏命令、接收溢出、忙时请求有明确行为；不执行残缺命令 |
| 验证 | 自检仿真、独立STM32输入、PWM回环、复位测试、60分钟运行记录、12MHz时序检查 |

规定测试输入的高、低电平各至少持续5个主时钟周期（约0.417μs），这是本项目主动选取的保守接口条件，不是器件手册给出的最高性能。1ms脉冲很适合初始实验。极窄脉冲、极端占空比和高速事件传递需要另行设计捕获/握手机制。

1秒门控测频存在边界量化（通常约±1个计数）、参考时钟误差和输入采样影响；周期/脉宽测量也有量化误差。FPGA发PWM再测自身的回环只能验证逻辑一致性，不能证明绝对频率准确。PC换算使用f≈12000000/period_ticks、t=ticks/12000000，并检查valid/timeout。

不要求在FPGA内做除法、浮点、十进制格式化或绘制界面。第87天可选第二通道/缓存/显示扩展；只有核心验收完成才做。

## 学习资料：按需查，不堆阅读量

1. [iCESugar官方仓库](https://github.com/wuxx/icesugar)：核对板型、烧录、iCELink与板级示例。硬件接线优先服从本次附件和实物版本。

4. [Icarus Verilog文档](https://steveicarus.github.io/iverilog/)：仿真编译、运行及语言支持。
5. [Yosys入门](https://yosyshq.readthedocs.io/projects/yosys/en/latest/getting_started/index.html)与[nextpnr官方仓库](https://github.com/YosysHQ/nextpnr)：综合、布局布线和报告阅读。
6. [Open FPGA Verilog Tutorial](https://github.com/Obijuan/open-fpga-verilog-tutorial/wiki/Home_EN)：用于概念与循序渐进的实验参考。原教程针对其他iCE40板型且部分流程较旧，不能直接照抄其引脚、器件、时钟、arachne-pnr或烧录命令。

资源核对日期：2026-09-17。每日教学可引用上述资料；后续需要查询更新行为时再核验官方文档。

## 每日记录与毕业检查

推荐每天记录5行：今天目标；实际完成；一张关键波形或一组实测数字；一个错误及原因；明天还需补什么。项目目录可用rtl/、tb/、constraints/、scripts/、docs/和build/；build为生成物，源码和约束纳入Git。

毕业时应能独立回答：wire与reg有什么区别？为什么时序逻辑用非阻塞赋值？为什么漏写组合分支会推断锁存器？两级同步器为什么不能抓住任意窄脉冲？tick与新时钟域有什么区别？UART如何定点采样？FIFO满了怎么办？何时需要快照？报告里的关键路径意味着什么？为什么仿真通过还要上板测量？

最终交付：源代码、可自动报错的测试、PCF、构建入口、验证过的bin、串口辅助程序、README、接线表、协议说明、测量记录和已知限制。可复现性优先于功能数量。
